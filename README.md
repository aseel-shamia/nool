# NOOL Store

متجر أزياء بالعربي والإنجليزي، فيه راك ملابس تفاعلي وغرفة قياس ولوحة تحكم.

- **المتجر (للزبائن):**https://aseel-shamia.github.io/nool1/
- **لوحة التحكم (للأدمن):** https://aseel-shamia.github.io/nool1/admin.html

## الملفات

| الملف | شو هو |
|---|---|
| `index.html` | المتجر اللي بيشوفه الزبون |
| `admin.html` | لوحة التحكم: المنتجات، الإعدادات، الطلبات، النشر |
| `store-data.js` | المنتجات والإعدادات (بيتحدّث من الأدمن) |
| `img/` | صور المنتجات والمودل |
| `og.jpg` | الصورة اللي بتطلع لما حدا يشارك الرابط |

الملفات لازم تضل مع بعض بنفس المكان وبنفس الأسماء.

## شو بيقدر يعمل الزبون

راك تفاعلي، صفحة لكل قطعة (صور، تفاصيل، مقاسات، كمية لكل مقاس)، غرفة قياس، مفضلة، سلة، كود خصم، توصيل حسب المنطقة، دفع (عند الاستلام، جوال باي، بنك فلسطين، PayPal، فيزا)، صفحة تأكيد ومتابعة الطلب، إرسال الطلب على واتساب، عربي وإنجليزي، وضع داكن.

## شو بيقدر يعمل الأدمن

إضافة وتعديل وحذف القطع (مع قص الخلفية وضبطها على المودل)، تغيير اسم الموقع ومعلومات التواصل وأسعار التوصيل وطرق الدفع وأكواد الخصم، متابعة الطلبات وتغيير حالتها، والنشر على الموقع بزر واحد.

## التشغيل (مرة وحدة)

1. **النشر من الأدمن:** اعمل مفتاح GitHub (Fine-grained token) للريبو `nool-store1` بصلاحية **Contents: Read and write**، وحطه بالأدمن.
2. **معلوماتك:** من الأدمن غيّر رقم الواتساب والهاتف والإيميل ورقم محفظة جوال باي وحساب البنك. الأرقام الحالية وهمية.
3. **قاعدة البيانات (Firebase):** حتى تنحفظ كل الطلبات بمكان واحد والكميات تنقص لحالها. الخطوات مكتوبة بالأدمن تحت "كيف أربطها؟".
4. **إيميل لكل طلب:** مفتاح من web3forms.com بالأدمن.
5. **الإحصائيات:** Measurement ID من Google Analytics بالأدمن.
6. **الدفع الحقيقي بـ PayPal وفيزا:** حساب PayPal Business، وحط الـ Live Client ID بالأدمن. هلأ هو بوضع الاختبار (`test`).

## ملاحظات

- الدفع بـ PayPal وقاعدة البيانات بيشتغلوا بس والموقع مرفوع على الإنترنت، مش لما تفتح الملف من جهازك.
- إذا غيّرت اسم الريبو، غيّر رابط `og.jpg` بأول `index.html`، واسم الريبو بالأدمن.
- رسمة المودل للرسّام UNKNOWNFOREST، وصور المنتجات الحالية للتجربة. بدّلها بصور إلك قبل البيع الحقيقي.
